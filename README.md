## Installation & Running Code
To compile and run the code locally:

1. **Install GCC** (if not already installed):
   - On Windows: [Install MSYS2](https://www.msys2.org/) and use the MSYS2 terminal to install GCC.
   - On macOS: Use Homebrew: `brew install gcc`
   - On Linux: Use your package manager: `sudo apt install gcc` (Ubuntu/Debian)

2. **Clone this repository:**
```bash
git clone https://github.com/truongbaan/EEET2601_Engineering-Computing-1.git
```

3. **Navigate into the directory:**
```bash
cd EEET2601_Engineering-Computing-1
```

4. **Compile a file:**
```bash
gcc -o output filename.c
```

5. **Run the compiled file:**
```bash
./output
```
